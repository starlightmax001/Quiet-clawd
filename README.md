Quiet Clawd 🦀

SHUT THE FUCK UP! CLAUDE!

Stop stealing my screen. Stop interrupting my work. Just do your job.

Quiet Clawd is a lightweight Claude Code plugin designed to automatically minimize unwanted windows, prevent focus interruptions, and keep Claude Code running quietly in the background.

No more annoying pop-ups, unexpected window switching, or desktop clutter.

1. Features

1. Automatic Window Minimization — Detects and minimizes unwanted windows launched by Claude Code.
2. Focus Protection — Reduces interruptions caused by applications stealing focus.
3. Smart Pop-up Detection — Handles terminals, browsers, loading screens, and secondary windows.
4. Background Monitoring — Automatically monitors window activity during Claude Code sessions.
5. Close Protection — Prevents accidental termination of active Claude Code PowerShell sessions.
6. Customizable Settings — Adjust monitoring behavior through a JSON configuration file.
7. Cross-Platform Support — Supports Windows, macOS, and Linux X11, with platform-specific limitations.

2. Installation

1. Download and extract Quiet Clawd.
2. Run install.cmd on Windows.
3. Wait for the installation confirmation.
4. Restart Claude Code.

Requirements: Claude Code and Node.js.

3. Commands

1. Pause: /quiet-clawd:quiet pause
2. Resume: /quiet-clawd:quiet resume
3. Status: /quiet-clawd:quiet status

Quiet Clawd starts automatically after installation.

4. Compatibility

Platform	Support
Windows 10/11	Full support
Linux X11	Window minimization
macOS	Limited support
Linux Wayland	Not supported

Note: Some windows may briefly appear before being minimized. Exclusive-fullscreen applications may still experience interruptions.
